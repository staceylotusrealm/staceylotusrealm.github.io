LOTUS REALM — Stacey's website
================================

Everything is in one file: index.html
Open it in any browser to look at it. Nothing to install.


WHAT IS STILL OPEN
------------------

Two spots are flagged inside index.html. Search the file for
class="todo" to find them. Both need a yes from Stacey before
they are treated as settled.

Her photo, her email address and her five services are all in.
Prices are deliberately off the page for now.


HOW TO FILL THEM IN
-------------------

Open index.html in any text editor.

Everything marked in yellow on the page is a placeholder.
Search the file for  class="todo"  to find each one.
Delete the  <span class="todo"> ... </span>  wrapper once you
replace the words inside it, and the yellow marking goes away.

Near the bottom of the file there is a block that looks like this:

    const CONFIG = {
      email: "",
      formEndpoint: "",
      instagram: "https://www.instagram.com/staceylotusrealm",
      facebook:  "https://www.facebook.com/staceylotusrealm"
    };

Put Stacey's email between the first pair of quote marks.
That switches on the email link and the contact form.


THE CONTACT FORM
----------------

As it stands, the form opens the visitor's own email app with
the message already written out, ready to send. That works
everywhere and costs nothing.

If Stacey would rather have messages land in her inbox on their
own, sign up free at formspree.io, and paste the address it gives
you into  formEndpoint  in the block above. The form then sends
by itself and shows a thank-you.


PUTTING IT ONLINE
-----------------

The address will be:  https://staceylotusrealm.github.io

That name comes from the GitHub account it lives under, so it has
to be created under an organisation called exactly
"staceylotusrealm". The name was free as of 6 Sept 2026.

  1. Go to github.com/organizations/plan and pick the Free plan.
  2. Name the organisation:  staceylotusrealm
  3. Then run this from inside this folder:

     gh repo create staceylotusrealm/staceylotusrealm.github.io \
       --public --source=. --push

It goes live a minute or two later. After that, updates are:

     git add -A && git commit -m "update" && git push

A real domain like staceylotusrealm.com costs about $12 a year from
any registrar. GitHub will serve it for free once it is bought, and
the github.io address keeps redirecting to it afterwards.
